1. **[CHAT-01] composer radius**: Codex's authored composer radius (20px/`--radius-3xl`) vs. [RAD-04]'s ruled 12px (`--radius-composer: 0.75rem`). Internal inconsistency between two parts of the same v2 doc — needs disambiguation on whether composer control-cluster gaps are 6px ([SPACE-01]) or 8px ([CHAT-02] prose); current repo implementation already uses 8px (`gap-2`).

Current repo placeholder (`text-muted-foreground`, 70%) is too opaque either way — real gap, recommend retuning to `--color-foreground-tertiary` (50%) as closest ruled match.
6. **[CHAT-04] readable/wide max-widths**: no existing tokens for 40rem readable / 64rem wide; genuinely NEW — must be added or the deviation (fluid-width transcript) consciously ratified.
7. **[CHAT-04] inter-message gap**: no existing `--transcript-turn-gap`-equivalent token; Codex's observed 12px sits between its own authored 16px/4px roles. NEW, needs a ruling if [CHAT-04] intends explicit pinning.
8. **[CHAT-05] tab strip height**: Conductor 40px vs. repo's shipped 28px (`--workspace-shell-tab-height`). [CHAT-05]'s prose is silent on height; recommend keeping 28px absent an explicit ruling.
9. **[CHAT-05] active-tab indicator structure**: Conductor uses an underline/bottom-border pattern; repo uses filled-overlay + full border. This is a structural (not just anatomy) difference — recommend treating as out of scope for [CHAT-05] unless the founder wants the underline redesign.
